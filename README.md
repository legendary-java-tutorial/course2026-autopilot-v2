# Учебный сайт

[![CI](https://github.com/legendary-java-tutorial/course2026-autopilot-v2/actions/workflows/ci.yml/badge.svg)](https://github.com/legendary-java-tutorial/course2026-autopilot-v2/actions/workflows/ci.yml)

Сайт на Markdown: страницы — в `pages/`, сборка — `npm run build` (HTML в папке `_site`), проверка страниц — `npm test`.

## Как запустить

```
npm ci
npm test
npm run build
```
